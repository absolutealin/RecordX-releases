# RecordX

Account review workstation for Roblox GovRP and MilRP communities.

## Download

**[⬇ Download RecordX for Windows](https://github.com/absolutealin/RecordX-releases/releases/latest/download/RecordX-Setup.exe)**

This link always gives the newest version.

## Install

1. Run `RecordX-Setup.exe` and follow the installer.
2. If Windows SmartScreen shows "Windows protected your PC", click **More info**, then **Run anyway**. The app is not code-signed yet.
3. Open RecordX and paste the license key your administrator gave you.

RecordX needs a license key to run. The installer on its own does not grant access.

## Updates

Once installed, RecordX checks for new versions by itself. When one is ready it asks you to restart, then installs it.

Older versions are listed under [Releases](https://github.com/absolutealin/RecordX-releases/releases).
